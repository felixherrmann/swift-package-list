# Tutorials

Follow these guides to generate acknowledgments and make them available to your users:

- [Acknowledgments Inside an iOS App](iOSApp.md): generate JSON during builds and display it with SwiftUI.
- [Acknowledgments in the Settings App](SettingsBundle.md): generate a new Settings Bundle.
- [Acknowledgments in an Existing Settings Bundle](ExistingSettingsBundle.md): update your app's existing settings during builds with a Run Script Phase.
- [Acknowledgments in a macOS App](macOSApp.md): generate a PDF during builds and open it from the app menu.
- [Acknowledgments from the Terminal](CommandLine.md): install the CLI, inspect dependencies and save a JSON package list.

These tutorials describe Swift Package List 5. The app tutorials use Xcode projects and require a Swift 6.2 or later toolchain. Start with an app that already uses Swift package dependencies.
