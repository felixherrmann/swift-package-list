# Swift Package List Documentation

Swift Package List generates dependency lists and acknowledgments, and provides Swift libraries to load and display them in your app.

- [Tutorials](Tutorials/README.md): step-by-step guides for iOS, the Settings app, macOS and the command line.
- [Command-Line Tool](CommandLineTool/README.md): installation, usage, build integration, output formats and custom packages.
- [Libraries](Libraries/README.md): loading package lists and displaying acknowledgments with UIKit or SwiftUI.
- [Migration Guides](Migrations/README.md): upgrade between major versions.
- [Architecture](Architecture.md): how generation, output formats and runtime libraries fit together.
