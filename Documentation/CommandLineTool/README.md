# Command-Line Tool

Generate dependency lists and acknowledgments from Xcode projects, Xcode workspaces, Swift packages and Tuist projects.

- [Installation](Installation.md): install with Homebrew, Mint or Mise.
- [Usage](Usage.md): supported project files, command-line options and package filtering.
- [Build Tool Plugin](BuildToolPlugin.md): generate files during builds and configure targets and environments.
- [Run Script Phase](RunScriptPhase.md): automate generation in Xcode, with Homebrew and Mint troubleshooting.
- [Tuist](Tuist.md): commands for supported dependency setups.
- [Custom Packages](CustomPackages.md): include additional packages and licenses.
- [Output Formats](OutputFormats.md): choose how to export dependencies and acknowledgments.
